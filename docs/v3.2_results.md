# SA2 V3.2 Results

**Date:** 2026-11-01  
**Confirmatory outcome:** The preregistered decision rule was **met** on the V3.2 blind cohort.

## 1. Headline (fixed thresholds, frozen before blind)

| Arm | TPR (95% Wilson CI) | FPR (95% Wilson CI) | ROC-AUC | PR-AUC |
|------|------|------|------|------|
| Baseline `pe_v1s` | 0.597 (0.548–0.643) | 0.63% (1/158) | 0.969 | 0.988 |
| Candidate `pe_v3` | **0.738** (0.694–0.779) | 0.63% (1/158) | 0.982 | 0.993 |

**Paired group bootstrap** (539 groups, candidate minus baseline):

- TPR: **+14.2 pp** (95% CI **+9.6 to +18.8**)
- FPR: 0.0 pp (95% CI 0.0 to 0.0)

| Preregistered condition | Result |
|------|------|
| TPR gain ≥ 2 pp | Met (+14.2) |
| Bootstrap CI lower bound > 0 | Met (+9.6) |
| Candidate FPR ≤ baseline FPR | Met (tie at 1/158) |
| **Improvement supported** | **Yes** |

This is the first blind evaluation in the SA2 V3 line that satisfied all three conditions. It does **not** imply SOTA, product readiness, or generalization beyond the stated corpus sources.

## 2. What changed in V3.2

Documented in `docs/v3.2_preregistration.md`:

1. **No isotonic calibration** (V3.1 failure mode removed).
2. **Median-of-fold thresholds** at **0.8%** training FPR target (selected from a closed OOF grid on the training pool only).
3. **64-bit malicious up-weighting** (3×) retained.
4. **Training pool:** V1 train + `new_train` from v3, v3.1, and v3.2 (**5,238** rows, 3,162 benign, 2,076 malicious, 1,088 groups).
5. **Benign sampling:** skip first 40 files per vendor bucket, prefer parent directories not seen in V1/V3/V3.1, include config `benign_roots`.

**OOF grid winner:** `target_fpr=0.008`, `threshold_mode=median_fold`, `use_weights=true` (delta TPR +11.5 pp vs baseline on train OOF at ~0.41% FPR).

## 3. Blind cohort limitations (must read with results)

| Limitation | Detail |
|------|------|
| Benign blind count | **158** benign files (not the preregistered 300+ target). Most install-directory `group_id` values were already used in V1/V3/V3.1, so few benign groups qualified for blind. |
| FPR resolution | One false positive is **0.63% FPR**. Baseline and candidate **tied** at exactly one false positive; the rule compares point estimates, not a statistical test on FPR equality. |
| Class imbalance in blind | 409 malicious vs 158 benign (malware-heavy blind). TPR is estimated more precisely than FPR. |
| Source scope | Same MalwareBazaar + local Windows/vendor install sources as earlier waves. |
| Overlap checks | 5 benign blind files share an imphash with training; 1 blind row had an identical PE-v3 feature vector to a training row (flagged in `disjointness`). |
| Tuning | The OOF grid (5 rows) was preregistered; it is still a small multiple-comparison surface on training data only. |

## 4. Matched-FPR (descriptive, blind)

See `artifacts/v3.2/blind/blind_results.json` → `matched_fpr_descriptive`. At 1% FPR on blind scores, the candidate remained ahead of the baseline (consistent with fixed-threshold gains).

- Time-split or geographically distinct malware.
