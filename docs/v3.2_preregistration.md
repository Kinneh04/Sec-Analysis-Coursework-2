# SA2 V3.2 Preregistration

**Registered:** 2026-11-01, before V3.2 fitting or blind evaluation.

## Goal

Improve **fixed-threshold** detection on a new blind cohort while keeping candidate FPR no higher than the baseline, after V3 (FPR too high) and V3.1 (isotonic thresholds collapsed to 0% TPR).

## Fixed model

LightGBM `lgbm__num_leaves-15_min_child_samples-20_feature_fraction-0.7` (unchanged from V3 search).

## Training pool

Frozen V1 `train` plus `new_train` from cohort tags **v3**, **v3.1**, and **v3.2**. No blind row from any cohort is loaded.

## Interventions (all pre-registered)

1. **No isotonic calibration** (V3.1 isotonic is excluded).
2. **Operational target FPR 1.0%** on out-of-fold scores (1,838+ benign rows in pool after V3.1).
3. **Threshold mode:** median of per-fold thresholds (each outer `GroupKFold` fold sets a threshold at the target FPR on that fold’s out-of-fold scores; the final threshold is the median). Pooled OOF threshold was used in V3/V3.1 and is not used here.
4. **Sample weight 3.0** for 64-bit malicious rows (`pe1s_machine` 34404).
5. **Benign sampling for v3.2:** prefer files whose `(root, parent_directory)` key was not present in V1/V3/V3.1 inventories; config `benign_roots` from `configs/local.yaml` are included in search paths.
6. **Malware sampling:** exclude all SHA-256 used in V1/V3/V3.1; at least 50% PE64 in newly drawn malicious files.

## Hyperparameter selection (train OOF only)

Before blind evaluation, a **closed development grid** on the full training pool (not blind) selects one configuration. Both arms use the same selected `target_fpr` and `threshold_mode`:

| `target_fpr` | `threshold_mode` | `use_weights` |
|------|------|------|
| 0.008 | median_fold | true |
| 0.010 | median_fold | true |
| 0.010 | pooled | true |
| 0.012 | median_fold | true |
| 0.010 | median_fold | false |

**Selection objective:** maximize `(TPR_pe_v3 − TPR_pe_v1s)` on pooled OOF at each arm’s threshold, subject to `FPR_pe_v3 ≤ target_fpr + 0.002`. Tie-break: higher `TPR_pe_v3`.

The selected row is frozen in `artifacts/v3.2/retrain/tuning_selected.json` before model export.

## Confirmatory blind

New **v3.2** blind split (group-aware; prior SHA/groups/imphash from V1 and v3/v3.1 forced to `new_train`).

**Decision rule (unchanged):** improvement only if TPR gain ≥ 2 pp, paired group-bootstrap 95% CI lower bound > 0, and candidate FPR ≤ baseline FPR at frozen thresholds.

## Secondary (descriptive)

Matched-FPR TPR on blind scores at 0.5% and 1.0% FPR.
