# SA2 V2 Methods (draft)

V2 extends V1 with **coverage-aware fusion (V2-A)** and **uncertainty-aware review (V2-B)** without re-extracting the 968-sample cohort. All V2 code lives under `src/v2/`; artifacts under `artifacts/v2/`.

Week 1 established input integrity, BN coverage summaries, V1 baseline reproduction from saved evaluations, and validation-only calibration diagnostics using frozen V1 PE models.

See `docs/v2_preregistration.md` for the locked grid and selection budget. Implementation of fusion/review arms begins in Week 2.
