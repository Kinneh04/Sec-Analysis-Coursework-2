SA2 Scan API v1

All endpoints need the header X-API-Key. Admins find and rotate the key on Admin → Sensors. A wrong or missing key returns 401.

MethodPathPurpose
GET/api/v1/pingConnection test. Returns server name, model tag, thresholds.
GET/api/v1/files/<sha256>Report JSON (200) or 404 if unknown. Poll until status is done or error.
POST/api/v1/filesMultipart: file + optional meta (JSON string). Returns 202 {sha256, status}; 415 if not a PE file, 413 if over 50 MB.
POST/api/v1/sensors/heartbeatJSON {sensor_id, hostname, agent_version, stats}. Used by SA2 Sentinel every 30 s.

Example (PowerShell)

$h = @{ "X-API-Key" = "<key>" }
Invoke-RestMethod -Headers $h {{ request.host_url }}api/v1/ping
curl.exe -H "X-API-Key: <key>" -F "file=@C:\path\app.exe" -F "meta={\"source\":\"api\"}" {{ request.host_url }}api/v1/files
