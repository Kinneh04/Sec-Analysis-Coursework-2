With Binary Ninja

Without Binary Ninja
EMBER2024's own decision: m = logit(EMBER2024) − logit(thr_R1). This fallback is part of the preregistered protocol; the verdict is then the pretrained EMBER2024 model alone.

What the evidence supports

  • V8 met its rule, V9 did not confirm it, V10 did. V9's gain had a 95% CI that included zero. V10, a larger independent cohort, met the preregistered rule.
    • {% if v10 and v10.delta is not none %}
  • The gain is small. On V10 at the frozen threshold the blend's TPR differed from EMBER2024 alone by {{ '%+.2f' % (100 * v10.delta) }} percentage points (95% CI {{ '%+.2f' % (100 * v10.delta_ci[0]) }} to {{ '%+.2f' % (100 * v10.delta_ci[1]) }}), with no added false positives.
    • {% endif %} {% if v10 and v10.strict %}
  • Worse at the strictest operating point. At 0.25% training FPR the blend gained {{ v10.strict.gained_tp }} detections and lost {{ v10.strict.lost_tp }} against EMBER2024 on V10 ({{ v10.strict.cand_tp }} vs {{ v10.strict.r1_tp }} true positives).
    • {% endif %}
  • Course samples. On the Sample1/Sample2 files the blend flagged 1 of 7 and EMBER2024 alone flagged 2 of 7 (docs/v10_sample12_results.md; qualitative, not a powered test).
  • Without Binary Ninja the verdict is EMBER2024 alone. In V10, Binary Ninja features were usable for {% if v10 and v10.coverage %}{{ '%.0f%%' % (100 * v10.coverage.benign) }} of benign and {{ '%.0f%%' % (100 * v10.coverage.malicious) }} of malware files{% else %}most files{% endif %}; the rest used EMBER2024's decision.
  • Static features only. The models see structure, not behaviour. Packed or compressed payloads may be missed.
  • File kinds in training. {% if nsis and nsis.malicious is defined %}The training pool held {{ nsis.benign }} benign and {{ nsis.malicious }} malware NSIS-like files{% if nsis.benign_flagged_r1 is number %}; EMBER2024 flagged {{ nsis.benign_flagged_r1 }} of the {{ nsis.benign }} benign ones{% endif %}. So few benign installers mean their false-positive rate is not well measured (NSIS detection is approximate). {% else %}Some installer formats were rare among benign training files, so their false-positive rate is not well measured.{% endif %} See Insights.
  • Signatures. EMBER2024 reads the structure of an embedded Authenticode signature but never checks whether it is valid. Validity is shown as context only.
  • Binary Ninja model. Trained on 1,256 training files with Binary Ninja features.
  • Research record. The earlier V3.2 bundle stays in the repository (python -m src.v3.score); it no longer drives verdicts.
