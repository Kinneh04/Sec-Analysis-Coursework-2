Limitations to keep in mind

  • Static features only. The model sees structure, not behaviour. Compressed payloads (installers, packers) are opaque to it.
  • Format bias. {% if ref.classes %}{{ ref.classes.nsis.malicious }} of {{ ref.classes.nsis.malicious + ref.classes.nsis.benign }} NSIS-like files in training were malware, so benign NSIS installers and uninstallers are frequently flagged{% else %}Installer formats seen mostly as malware in training are often flagged{% endif %}. See Insights.
  • Small benign test set. 158 benign blind files give only coarse FPR resolution (one false positive = 0.63%).
  • No signature input. Authenticode validity is shown as context but is not a model feature.
  • Not deployed: later EMBER2024 + Binary Ninja blends, because their gain did not replicate (V9).
