Each scan restarts Binary Ninja

For every file that needs Binary Ninja features, SA2 Scan force-closes binaryninja.exe, rewrites %APPDATA%\Binary Ninja\settings.json (backup settings.json.sa2scan_backup), relaunches it in intermediate analysis mode, then in full mode, then restores your settings and relaunches it. This closes any open Binary Ninja session and takes minutes per file. It matches how the research enforced analysis modes.

Set SA2_BN_MODE_SWITCH=off to use Binary Ninja's current mode (a deviation from the frozen method, recorded in each report), or SA2_BN=0 to disable it. This path has not been tested against a live Binary Ninja.

MethodPathPurpose
GET/api/v1/pingConnection test: server name, model tag (v8), deciding engine, thresholds.
GET/api/v1/files/<sha256>Full report JSON (200) or 404. Poll until status is done or error. Includes assessment, explanation and all_signals.
POST/api/v1/filesMultipart file + optional meta (JSON string). 202 {sha256, status}; 415 not a PE; 413 over 50 MB.
